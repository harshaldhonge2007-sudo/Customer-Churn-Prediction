# Customer Churn Prediction

A Machine Learning project that predicts whether a customer is likely to leave (churn) or continue using a company's service. This project uses customer data to train a classification model that helps businesses identify at-risk customers and improve customer retention strategies.

---

## 📌 Project Overview

Customer churn prediction is one of the most important applications of machine learning in business analytics. By analyzing customer behavior and account information, the model predicts the probability of a customer leaving the company.

The insights generated from this project can help organizations:
- Improve customer retention
- Reduce revenue loss
- Identify high-risk customers
- Make data-driven business decisions

## ▶️ How to Run

### Clone the Repository

```bash
git clone https://github.com/harshaldhonge2007-sudo/Customer-Churn-Prediction.git
```

### Navigate to the Project Folder

```bash
cd Customer-Churn-Prediction
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

Or install manually:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the notebook and run all cells.
